Gloucester High School's alumni site lived on NationBuilder, which the volunteers could no longer afford. With Abdelrahman Baba, I compared platforms, migrated it to WordPress so volunteers could keep it updated, and connected an alumni directory to a SQL table we filtered and managed from WordPress.
